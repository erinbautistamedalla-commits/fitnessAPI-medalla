# Fitness Tracker App

A full-stack fitness tracking application built as part of the Zuitt Full Stack Web Development Bootcamp.

## Overview

The Fitness Tracker App demonstrates a client/server architecture using a Vue.js frontend and a Node.js/Express backend connected to MongoDB.

The project was developed to practice building a full-stack application with authentication, API communication, database persistence, and a structured backend architecture.

## Tech Stack

### Frontend

* Vue.js
* JavaScript
* HTML5
* CSS3
* Vite
* Axios

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* REST API
* JWT Authentication
* bcrypt
* CORS
* dotenv

## Architecture

The application is separated into two repositories:

**Client**

* Vue.js frontend
* User interface and client-side application logic
* API communication with the backend

**Server**

* Node.js / Express.js backend
* Controllers
* Models
* Routes
* Authentication
* MongoDB data persistence

## Key Development Concepts

* Client/server architecture
* REST API development
* MongoDB data modeling
* Mongoose
* User authentication
* JWT-based authentication
* Password hashing with bcrypt
* API integration
* Backend routing and controllers
* Frontend deployment
